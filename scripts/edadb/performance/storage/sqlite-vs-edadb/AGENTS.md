# Frozen SQLite/EDADB control experiment

This directory contains a user-approved, frozen experiment and its conclusions.
Do not edit, rename, delete, regenerate, or replace its code, scripts, build
configuration, documentation, or results without explicit user approval for
the proposed change. Suggestions alone do not authorize implementation.

Keep new experiments in a separate sibling directory. Do not mix measurements
from different batches or silently replace the recorded results. Propose changes
to shared benchmark code, SQLite configuration, or dependencies that affect
reproduction before implementing them.

The readme is the index, alignment.md defines the current experiment, results.md
records its measured results and evidence, and archive/initial_checks.md preserves
the first control experiments. Generated databases, binaries, logs, and raw output
remain outside Git; retain reproduction commands and evidence provenance in docs.

This is an agent workflow rule, not an operating-system write restriction.
